How it works

1 · Describe

Say what you want in English.

Claude writes a complete FastMCP server — real HTTP calls, typed inputs, meaningful errors. No boilerplate, no OpenAPI spec required.

2 · Chat

Talk to your new agent.

An in-browser chat panel loads the server's tools and hands them to Claude. Ask for something; it picks the right tool, calls the API, and answers.

3 · Verify

Prove it doesn't lie.

Tempered fires schema-directed adversarial payloads at every tool. Silent success — accepting bad input as if it worked — gets caught before the agent trusts it.

What's next

  1. Near-term
    More preset connectors and GitHub Actions integration. A pre-verified catalogue of common APIs, plus tempered test as a CI gate so a regression in the API spec fails the PR.
  2. Mid-term
    Continuous conformance monitoring. Watch every published MCP server for schema drift and silent-success regressions. Alert on the ones that stop rejecting what they should.
  3. Mid-term
    A public "verified" badge for MCP servers. Auditable pass rate any SaaS vendor can put next to their listing. Standards win by adoption, not by features.
  4. Long-term
    The conformance bar the ecosystem cites. Registries and agent platforms adopt Tempered's suite as the ingestion gate. Broken servers stop reaching agents in the first place.
